# MVP Kapsamı

## MVP’de Olacaklar
Login, rol bazlı menü, dashboard, Dolibarr bağlantı ayarları, müşteri/ürün listeleri, stok görüntüleme, satış siparişi oluşturma, sipariş detay, depo hazırlama ekranı, tahsilat girişi, gün sonu raporu, Türkçe UI.

## MVP’de Olmayacaklar
Tam SaaS ödeme sistemi, otomatik paket satın alma, e-fatura entegrasyonu, gelişmiş muhasebe, native mobil uygulama, offline çalışma, yapay zeka özellikleri.

## İlk Ekranlar
Login, Dashboard, Cari Listesi, Cari Detay, Ürün/Stok Listesi, Ürün Detay, Hızlı Satış Siparişi, Sipariş Listesi, Sipariş Detay, Depo Hazırlama, Tahsilat Girişi, Gün Sonu Raporu, Ayarlar/Dolibarr Bağlantısı.
