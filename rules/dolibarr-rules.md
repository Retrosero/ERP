# Dolibarr Kuralları

- Dolibarr çekirdeğine dokunma.
- Dolibarr core dosyalarını override etme.
- Dolibarr veritabanına doğrudan yazma yapma.
- Yazma işlemlerinde Dolibarr REST API kullan.
- Okuma işlemleri için API önceliklidir.
- API key sadece backend tarafında saklanır.
- Frontend Dolibarr API’ye doğrudan istek atmaz.
- Dolibarr’dan gelen veriler mapping katmanından geçirilmelidir.
