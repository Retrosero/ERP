# Güvenlik Kuralları

- API key frontend’e çıkmaz.
- Kullanıcı şifreleri hash’lenir.
- Rol bazlı yetki uygulanır.
- Hassas loglar maskelenir.
- Yetkisiz API erişimi engellenir.
- Session güvenli cookie ile yönetilir.
- CSRF/XSS riskleri dikkate alınır.
- Teknik hata detayları kullanıcıya gösterilmez.
