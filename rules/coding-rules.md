# Kodlama Kuralları

- TypeScript kullan.
- `any` kullanımından kaçın.
- Servis katmanlarını modüler tut.
- Dolibarr API çağrılarını tek bir client üzerinden yap.
- Componentleri küçük ve tekrar kullanılabilir yaz.
- Form validasyonlarında Zod kullan.
- Hata mesajlarını Türkçe göster.
- API key, token ve bağlantı bilgilerini frontend’e çıkarma.
- Environment variable kullan.
- Büyük componentlerde iş mantığını hook/service dosyasına taşı.
- UI bileşenleri ile veri çekme mantığını mümkün olduğunca ayır.
